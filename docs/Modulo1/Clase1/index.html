Concepto central

La pantalla es una función de los datos

Tú describes cómo se ve la página para unos datos dados; React se encarga de ponerlo en el navegador.

En la Clase 0 hiciste las dos cosas tú: describir (el template literal) y poner en pantalla (innerHTML, renderizar(), addEventListener después de cada pintura). React te quita la segunda parte.

3.1 · Qué es React

Definición técnica

React es una librería de JavaScript para construir interfaces de usuario a partir de componentes: funciones que reciben datos y devuelven la descripción de lo que se ve.

Explicación sencilla

Es una forma de armar la página con piezas propias, como <TarjetaClase />, que se escriben una vez y se usan muchas veces, cada una con sus datos.

Aplicación profesional: la portada, el listado y las "Recomendadas" de Valeria usan la misma TarjetaClase. El sobrino cambia el tono del botón en un solo archivo y cambia en las tres secciones.

3.2 · Componente, la idea central

Definición técnica

Un componente de React es una función de JavaScript cuyo nombre empieza con mayúscula y que devuelve JSX.

En la vida real

Un molde de galletas. Se diseña una vez y se usa con distintas masas. La tarjeta es el molde; cada clase del gimnasio es una masa distinta.

3.3 · Por qué se usa

Reutilizar

Una pieza, muchos usos. Es lo que pide Valeria.

Dividir el trabajo

Cada componente es un archivo pequeño con una sola responsabilidad. Dos personas pueden trabajar en el encabezado y en la tarjeta sin pisarse.

No desincronizar

Cuando el dato cambia por el camino que React conoce, React repinta solo. Hoy vas a ver qué pasa cuando el dato cambia por fuera de ese camino; la Clase 2 lo arregla.

4.3 · Crear el proyecto con Vite

Definición técnica

Vite es una herramienta de construcción para el frontend. Trae un servidor de desarrollo que entrega tus archivos al navegador, traduce el JSX a JavaScript que el navegador entiende y recarga la página cuando guardas.

6.2 · Las reglas de JSX

Definición técnica

JSX es una extensión de la sintaxis de JavaScript que permite escribir etiquetas parecidas a HTML dentro del código. No es HTML ni un texto: cada etiqueta se traduce a una llamada de JavaScript que describe un elemento.

Explicación sencilla

En la Clase 0 escribías el HTML como texto entre comillas invertidas y lo pegabas con innerHTML. En JSX lo escribes sin comillas, directamente en el código, y React se encarga de convertirlo en elementos reales.

Las cuatro reglas que más se rompen

Los valores de JavaScript van entre llaves${clase.nombre}{clase.nombre}

className existe porque class es una palabra reservada de JavaScript (sirve para declarar clases). Como JSX es JavaScript, React usa el nombre que tiene esa propiedad en el DOM: className.

Probar · errores

Leer el síntoma antes de cambiar código

El mensaje indica si falló el entorno, una ruta, JSX, una prop o el flujo del evento.

13.1 · Entorno y npm

'npm' no se reconoce

Cómo se lee: la terminal no encuentra el programa npm.
Causa: Node no está instalado, o Cursor se abrió antes de instalarlo.
Solución: instala Node LTS desde nodejs.org, cierra Cursor por completo y vuelve a abrirlo. Comprueba con node -v.

Could not read package.json

Cómo se lee: npm buscó package.json en la carpeta actual y no lo encontró.
Causa: ejecutaste el comando desde pulsofit-fullstack/ y no desde frontend/.
Solución: cd frontend y repite el comando.

Tailwind no hace nada

Causa: falta tailwindcss() en vite.config.js, index.css no tiene @import "tailwindcss";, o el servidor no se reinició.
Solución: revisa los dos archivos, detén el servidor con Ctrl+C y vuelve a ejecutar npm run dev.

13.2 · Traducción de JSX e imports

Failed to resolve import

Cómo se lee: un archivo pide importar otro que no existe en esa ruta.
Causa: borraste App.css y App.jsx todavía lo importa, o hay una ruta mal escrita.
Solución: reemplaza App.jsx o corrige la ruta letra por letra.

Adjacent JSX elements

Cómo se lee: el componente intenta devolver dos o más elementos sueltos.
Causa: falta el elemento raíz.
Solución: envuelve todo en un div, un main… o un fragmento <> … </>.

does not provide an export named 'default'

Cómo se lee: se importó lo principal de un archivo que no exporta nada por defecto.
Causa: falta export default NombreDelComponente;.
Solución: agrégala. Si el archivo exporta con nombre, el import va con llaves.

TarjetaClase is not defined

Cómo se lee: se usó una palabra que ese archivo no conoce.
Causa: falta el import en el archivo que usa el componente.
Solución: agrega el import arriba del archivo donde aparece la etiqueta.

13.3 · Props, listas y eventos

Cannot read properties of undefined

Cómo se lee: se intentó leer .nombre de algo que vale undefined.
Causa: el nombre de la prop no coincide.
Solución: el nombre a la izquierda del = debe ser exactamente el que está entre las llaves de la función.

unique "key" prop

Cómo se lee: una lista hecha con map no tiene key.
Causa: falta key={clase.id}.
Solución: agrégala en el elemento que devuelve el map, no dentro de TarjetaClase.

Invalid DOM property 'class'

Cómo se lee: se usó el nombre de HTML en lugar del de JSX.
Solución: cambia class= por className=.

Lista vacía sin error

Causa: el map usa llaves sin return: clases.map((clase) => { <TarjetaClase … /> }).
Solución: cambia las llaves por paréntesis, o escribe return.

onReservar is not a function

Cómo se lee: el botón llamó a una prop que no trae ninguna función.
Causa: algún eslabón no pasa onReservar.
Solución: sigue el camino App → ListaClases → TarjetaClase y revisa que cada uno la reciba y la entregue.
